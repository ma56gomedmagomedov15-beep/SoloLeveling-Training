# SystemLevelUp — Solo Leveling Training

Небольшой браузерный игровой прототип по мотивам Solo Leveling.

## Запуск локально
Откройте `index.html` в браузере.

## Публикация через GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html`, `style.css` и `main.js` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет ссылку на игру в разделе Pages.

## Управление
- ПК: WASD или стрелки для движения, пробел для атаки.
- Телефон: экранные кнопки; можно нажать на монстра на игровом поле.
- За победу над монстром даётся 25 XP.
- Призыв тени стоит 50 XP и увеличивает атаку.

Это фанатский учебный прототип, неофициальный проект.
